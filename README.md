# My Planner

大学生活の「目標・今日のタスク・授業・課題・習慣」を1つにまとめた iPhone アプリ（SwiftUI）。

複数のアプリ（カレンダー、ToDo、メモ、成績管理）を行き来するのが面倒だった自分の課題から作りました。

## 機能

8つのタブで構成しています。

| タブ | 内容 |
|---|---|
| Goals | 長期目標の登録と達成チェック、達成数の表示 |
| Today | 当日のToDo（日付が変わると自動リセット）、種類別リマインダー、周期トラッカー |
| Calendar | 日ごとの予定をタイムブロックで表示、色分け |
| Projects | プロジェクト単位でタスクを管理、進捗表示 |
| Habits | 習慣トラッカー。週・月・年の3表示、連続日数（ストリーク）と達成率 |
| Classes | 授業ごとに評価項目（中間・期末・課題など）と配点比率を登録し、採点済み項目から現在の成績を加重平均で算出。A〜Fと色で表示 |
| Notes | メモ。ピン留め対応 |
| Submit | 課題・提出物の締切とステータス（未着手〜提出済み）管理 |

## 技術

- Swift / SwiftUI
- `@Observable` による画面ごとの状態管理（Store クラス）
- `Codable` + `UserDefaults` でローカル保存（サーバー不要、オフラインで動作）
- 外部ライブラリなし
- 対象：iOS 26.4 以上

## 工夫した点

- **データ構造を画面ごとに分離**：Goals / Today / Habits などそれぞれに Store を持たせ、機能追加しても他の画面に影響しないようにした
- **成績の算出**：未採点の項目を除外し、採点済みの配点比率だけで正規化して加重平均を出すため、学期途中でも現状の成績がわかる
- **習慣の記録**：日付を `yyyy-MM-dd` 文字列で保存し、ストリークと期間別達成率を同じデータから計算
- **ToDoの日次リセット**：最終保存日を記録し、起動時に日付が変わっていれば当日分を自動でクリア
